# Glossary

| Term | Description |
| --- | --- |
| Compat | Legacy-compatible API path focused on migration ease. |
| FastPath | Performance-oriented native API path. |
| P0 / P1 | Priority stages in performance roadmap. |
| draw call | Number of draw submissions to GPU. |
| dirty rect | Region-based redraw information. |
| equivalence test | Tests proving behavior parity between Compat and FastPath. |
