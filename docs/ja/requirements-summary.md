# 要件サマリー

## 1. 目的
Rust で GPU レンダリング可能な WebUI エンジンを実装し、既存エンジンの代替として採用可能な状態を目指す。

## 2. MVP 要件
- ウィンドウ生成と GPU 初期化
- 矩形/線の基本描画
- リサイズ対応
- マウス/キーボード入力
- 最小 UI ツリー更新
- Compat 経由で既存画面を最低1つ再現

## 3. 性能要件
- 平均フレーム時間: 16.6ms 以下
- p95 フレーム時間: 20ms 以下
- draw call: 主要画面で 200 以下
- 無更新フレームで再描画抑制

## 4. 互換・移行要件
- Node/Style/Event の主要概念を互換レイヤーで吸収
- 既存 API -> 新 API のマッピング表を維持
- 新旧エンジン共存を可能にし段階移行する

## 5. 品質要件
- Compat/FastPath 同等性テスト必須
- MUST API は破壊的変更を厳格管理
- PR で P0/P1 CI ゲートを通過させる

## 6. 代替判定基準
- API 代替率: 80%以上
- 画面再現率: 90%以上
- 速度: 既存比で有利、または同等で CPU/GPU 使用率を削減
