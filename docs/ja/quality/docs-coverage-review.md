# docs 追加検討の確認結果

## 1. 既存で十分だった領域
- 要件詳細
- crate 構成
- 高速化計画
- API マッピング
- API スワップ品質
- CI ゲート運用

## 2. 追加した方がよいと判断した領域
1. 開発運用
- 追加: `contributing.md`
- 理由: 変更時の同時更新ルールとPR観点を明確化するため

2. 共通言語
- 追加: `glossary.md`
- 理由: Compat/FastPath などの用語の誤解を減らすため

3. 設計判断の履歴
- 追加: `architecture-decisions.md`
- 理由: 将来の意思決定背景を追跡できるようにするため

4. 英語版入口
- 追加: `en/*`
- 理由: 英語話者向けに主要ページを短時間で共有するため
