# 用語集

| 用語 | 説明 |
| --- | --- |
| Compat | 既存エンジン互換 API 経路。移行しやすさを優先する。 |
| FastPath | 性能優先の独自 API 経路。低オーバーヘッドで描画する。 |
| P0 / P1 | 速度最優先ロードマップの段階。P0 は計測 + ホットパス、P1 はバッチング効果。 |
| draw call | GPU への描画命令発行回数。少ないほど CPU 負荷が下がりやすい。 |
| dirty rect | 変更領域のみ再描画するための矩形情報。 |
| equivalence test | Compat と FastPath の挙動同等性を確認するテスト。 |
